# ChunBall Remix

玉が転がり、ギアが回り、仕掛けが動く。ChunBallは、スコアもクリア条件もない「物理おもちゃ」です。
仕掛けを組み立てたり、予想外の動きを眺めたり、自分のペースで遊んでください。

- [本家ChunBall](https://chunball.pages.dev/)
- [Grok版ChunBall](https://chunball.grok.me/)

このリポジトリは、コンバインステージを含まない4ステージ版です。本家Cloudflare版とRemix版は別管理で、上記サイトとこのソースの内容・バージョンが常に一致するとは限りません。

## 4つのステージ

| ステージ | 楽しみ方 |
| --- | --- |
| 下水道 | 管や槽を流れる玉を眺め、仕掛けを足して流れを変える |
| フリー | 用意された流れに線や機械を加えて試す |
| 完全フリー | カゴから64個の玉を放出し、自由に搬送路を組む。玉がなくなると補充される |
| 洗濯機 | 洗濯機の運転やギア出力を使って、回転が伝わる仕組みを楽しむ |

## 基本操作

- 上部のアイコンでステージを切り替えます。
- 画面をドラッグして線を描き、玉の道を作ります。
- 右側のツールボックスから、ギアやクローラーなどをドラッグして配置します。
- 動力ギアは方向と5段階の速度を選択できます。従動ギアは玉やほかの機構から力を受けて回ります。
- フリーベルトを選び、始点へ戻る輪を描くと自由形状のベルトになります。内側ローラー接続と外側の摩擦駆動を試せます。
- 消しゴムで配置物を消せます。ツールボックスは左側面の取っ手で移動できます。
- 保存アイコンからセーブ・ロードできます。保存先はそのブラウザ・サイトごとです。別のサイトや端末へ自動同期はしません。
- 完全フリーでは上部の玉アイコンでカゴから放出、洗濯機では画面内の電源ボタンで運転します。

マウスとタッチを扱う実装です。ただし、このRemix分離版のSafari・iPad実機での網羅的な確認は未完了です。

## ローカルで動かす

Node.jsとnpmを用意し、リポジトリのディレクトリで実行します。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5202 --strictPort
```

`http://127.0.0.1:5202/` を開いてください。依存のインストールにはネット接続が必要です。
これまでのビルド検証環境はNode.js 26.5.0 / npm 11.17.0です。他のバージョンの動作を一律に保証するものではありません。

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 5203 --strictPort
npm test
```

ビルド出力は `dist/`。テストには長時間・負荷検証が含まれます。
元版との軌道比較だけは、別の読み取り専用チェックアウトを用意し、`BASELINE_ROOT=/path/to/original npm test` で実行します。
通常の `npm test` ではこの比較をスキップします。

## 構成・互換性

- `src/`：4ステージ、Canvas描画、入力、ギア・ベルト物理、保存。
- `scripts/`：PWA生成と回帰テスト。
- `public/`：静的配信設定。図形・PWAアイコンは主にコードで生成します。
- 保存v1〜v3の非コンバイン配置を扱い、保存キーは `chunball.remix.save.slot.*` に分離しています。
- PWAはビルド版で動作します。開発サーバーでの起動確認は、オフライン確認とは別です。
- 本家と同じオリジン・同じService Workerスコープに上書き配信しないでください。
- 64個密集時のFPSによる挙動差は既知事項です。
